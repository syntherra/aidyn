# Security & Compliance

## Auth & Access
- Firebase Authentication for users; OAuth for email integrations
- Token-based API calls over HTTPS; secrets in Firebase Secrets Manager

## Data Protection
- PII encrypted at rest and in transit
- PII stored in segregated collections with strict rules
- Audit logging for all access/modifications

## Compliance
- GDPR/CCPA: data export, deletion, suppression workflows
- Unsubscribe enforcement and suppression lists across CRM and campaigns

## Operational Security
- No secrets in repo; use secrets managers
- Regular domain warm-up and inbox health monitoring
