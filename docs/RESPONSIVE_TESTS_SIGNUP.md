# Responsive Test Cases

- Desktop 1512×982: layout matches Figma, spacing and shadows, input widths full.
- Desktop 1280: container scales, card retains padding `50/90`, left graphic scales.
- Tablet 768–1024: columns stack, card full-width, elements maintain hierarchy.
- Mobile 360–640: card padding `24px`, inputs hit targets ≥48px, text wraps without overflow.
- Keyboard: Tab order follows form, focus indicators visible, Enter submits.
- Errors: invalid email and short password show messages with `role=alert`.
- Loading: button shows loading state, disabled.
- Success: confirmation replaces form.
